Hipoteza HMH ocenia wytężenie przez energię zmiany postaci, a nie przez samą zmianę objętości. Jednostajne ściskanie ze wszystkich stron zmienia objętość, ale nie zmienia kształtu, dlatego w modelu HMH nie zwiększa naprężenia zredukowanego.

<Lab id="mohr" />

<Formula>
$$
\sigma_{HMH} = \sqrt{\sigma_1^2 + \sigma_2^2 + \sigma_3^2 - \sigma_1\sigma_2 - \sigma_2\sigma_3 - \sigma_3\sigma_1}
$$

<Caption>Dla płaskiego stanu naprężenia przyjmujemy σ3 = 0. Gdy σx = σ, σy = 0 i τxy = τ, wzór upraszcza się do σHMH = √(σ² + 3τ²).</Caption>
</Formula>

<Insight>
Przy czystym ścinaniu HMH daje σred = √3·τ. Wynika stąd, że granica plastyczności przy ścinaniu wynosi Re/√3, a nie Re — to częsty błąd w zadaniach.
</Insight>

<WorkedExample>
<Given>
Wał ma w pewnym punkcie σ = 80 MPa oraz τ = 60 MPa. Materiał ma Re = 235 MPa.
</Given>
<Steps>
<Step>
Dla płaskiego stanu z σx = σ, σy = 0 i τxy = τ stosujemy σHMH = √(σ² + 3τ²).
</Step>
<Step>
σHMH = √(80² + 3·60²) = √17 200 = 131,15 MPa.
</Step>
<Step>
Współczynnik bezpieczeństwa: n = Re/σHMH = 235/131,15 = 1,79.
</Step>
</Steps>
<Result>
Naprężenie zredukowane HMH wynosi 131,2 MPa, a współczynnik bezpieczeństwa około 1,79.
</Result>
</WorkedExample>

<Hint>
Użyj √(σ² + 3τ²), nie √(σ² + τ²).
</Hint>
<Explanation>
σHMH = √(100² + 3·50²) = √17 500 = 132,29 MPa. Czynnik 3 przy τ² wynika z pełnego wzoru HMH; pominięcie go zaniżyłoby wynik.
</Explanation>

</Explanation>
